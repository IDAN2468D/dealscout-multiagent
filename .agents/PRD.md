# 📄 Product Requirements Document (PRD) — DealScout AI (`dealscout-multiagent`) v2.1

## 1. תקציר מנהלים והגדרת הבעיה
צרכנים המחפשים עסקאות משתלמות באתרי קניות ו-E-commerce מתמודדים עם שישה אתגרים מרכזיים:
* **פיצול חנויות ועלויות נסתרות:** אותו מוצר נמכר במחירים שונים באמזון, אליאקספרס, eBay, ASOS ורשתות מקומיות (כגון KSP וטרמינל X), אך המחיר המוצג אינו משקף משלוח, המרות מט"ח ומע"מ/מכס ביבוא אישי.
* **קופונים שבורים והטבות מועדון מפוזרות:** אתרי קופונים מלאים בקודים פגי תוקף, ובמקביל צרכנים מפספסים הנחות של מועדוני אשראי/צרכנות שבבעלותם או אפשרויות ל-Coupon Stacking.
* **מבצעים פיקטיביים (Fake Discounts):** חנויות מעלות מחירים שבועות לפני סיילים כדי להציג אחוז הנחה מלאכותי.
* **מלכודות מס ומפרט ביבוא אישי:** הזמנה מרוכזת של מספר פריטים חוצה לעיתים את רף הפטור ממס (75 דולר) וגוררת תוספת מע"מ של 18% שניתן היה לחסוך בפיצול חבילות חוקי; בנוסף, מוצרי חשמל מחו"ל מגיעים לעיתים במתח 110V שאינו מתאים לישראל.
* **חוסר התאמה אישית ומעקב:** חיפוש אנונימי דורש מהמשתמש להזין בכל פעם מחדש תקציב, ארץ משלוח, מועדוני אשראי והעדפות אחריות.
* **סיכוני אבטחה והונאות:** חנויות מתחזות, ביקורות בוטים, וסיכון של הזרקות פרומפט (Prompt Injection) בתוך תיאורי מוצר או פורומים של קופונים.

## 2. חזון המוצר, מנוע ה-AI ומסלולי משתמשים (SaaS Tiers)
**DealScout AI (`dealscout-multiagent`)** היא פלטפורמת SaaS אישית ומאובטחת המופעלת על ידי צוות סוכנים אוטונומי (Multi-Agent Backend) המבוסס על **`gemini-3.5-flash-lite`** של Google. בחירת המודל מאפשרת הרצה מקבילית של תתי-סוכנים בחביון נמוך, ניתוח תמונות ודפי מוצר באופן מובנה (Multimodal Vision & URL Context), חיפוש מבצעים חי (Google Search Grounding) ושמירה על עלות תפעול נמוכה פר-חיפוש באמצעות Context Caching.

המערכת מזהה את המשתמש, מתאימה את החיפוש לפרופיל הקונה ולמועדוני האשראי שלו, מאמתת קופונים, מזהה הנחות פיקטיביות ובעיות תאימות, ומחשבת באופן דטרמיניסטי את **המחיר הסופי האמיתי עד הבית (Effective Landed Cost)** כולל אופטימיזציית פיצול סל.

### קהל יעד ומסלולי שימוש (RBAC & Tiers)
| מסלול / תפקיד | הרשאות ומכסות |
| :--- | :--- |
| **`FREE`** | עד 10 חיפושי סוכנים ביום, עד 3 מוצרים ב-Watchlist, התראות מייל בלבד, גישה להשוואת מחירים וקופונים מאומתים |
| **`PRO`** | חיפושים ללא הגבלה, עד 50 מוצרים ב-Watchlist עם סריקת Kafka תכופה, התראות Telegram/Slack, אופטימיזציית פיצול סל, חיפוש מולטי-מודאלי לפי תמונה/קישור וזיכרון ארוך-טווח |
| **`ADMIN`** | ניהול חנויות וקטלוג, אישור/חסימת מוכרים, מודרציית קופוני קהילה, צפייה ביומני ביקורת (Audit Logs) ובלוח ניטור עלויות טוקנים של Gemini |

## 3. דרישות פונקציונליות ליבה

### 3.1 הרשמה, התחברות, הרשאות ופרופיל קונה אישי
* **אימות מאובטח:** הרשמה והתחברות עם אימייל וסיסמה (הצפנת `Argon2id`), אימות כתובת מייל, הנפקת `JWT Access Token` קצר-מועד ו-`Refresh Token` מאובטח ב-`HttpOnly Cookie` עם Rotation וביטול מיידי ב-Redis.
* **התחברות מהירה (SSO):** תמיכה ב-**Google OAuth2**.
* **פרופיל קונה וארנק מועדונים (`UserBuyerProfile`):** שמירה חד-פעמית של מועדוני צרכנות וכרטיסי אשראי (שמות מועדונים בלבד כגון *הייטקזון, חבר, פליי קארד, מקס* — ללא שמירת פרטי כרטיס אשראי), מטבע מועדף, ארץ משלוח, מידות וסף אמינות מינימלי למוכר.
* **סוכנים מודעי-הרשאות (Multi-Tenancy):** בידוד מלא לפי `user_id` — כל סוכן וכלי MCP רשאים לגשת אך ורק ל-Watchlist, לאישורי ה-Checkout ולפרופיל של המשתמש המחובר.

### 3.2 תזמור רב-סוכנים על בסיס `gemini-3.5-flash-lite` (`deal-orchestrator-agent`)
* קליטת בקשת קנייה בשפה חופשית, מיזוג אוטומטי עם `UserBuyerProfile` וזיכרון ארוך-טווח (העדפות עבר כגון אחריות יבואן רשמי או זמן משלוח מקסימלי).
* הפעלה מקבילית של תתי-הסוכנים על גבי `gemini-3.5-flash-lite` והזרמת תוצאות ביניים ודירוג סופי ב-SSE.

### 3.3 איתור מוצרים וחיפוש מולטי-מודאלי (`store-search-mcp-agent` + `multimodal-product-matcher`)
* חיפוש מהיר ב-Elasticsearch עם Fuzzy Matching, בשילוב **Google Search Grounding** של Gemini לאיתור מבצעים חיים ברשת.
* **חיפוש לפי קישור או תמונה:** הדבקת URL של מוצר או העלאת צילום מסך; חילוץ דגם, מק"ט (`SKU` / `UPC` / `ASIN`) ומפרט באמצעות יכולות ה-Vision וה-`url_context` המובנות ב-`gemini-3.5-flash-lite`.

### 3.4 ציד קופונים, מועדונים ואימות קהילתי (`coupon-hunter-rag-agent`)
* שליפה סמנטית ממאגר וקטורי (ChromaDB) של תנאי קופונים, Coupon Stacking והטבות מועדוני האשראי של המשתמש, תוך שימוש ב-**Gemini Context Caching** להוזלת שליחת מסמכי מדיניות קבועים.
* אימות Dry-Run דרך `coupons_mcp` ושילוב מנגנון **Crowd-Verified Coupons**: משתמשים רשומים מדווחים האם הקופון עבד, ומעדכנים ציון `success_rate` בזמן אמת ב-Redis.

### 3.5 ביקורת היסטוריית מחירים, ביקורות ותאימות (`price-history-auditor` + `review-compatibility-auditor`)
* הצלבת המחיר הנוכחי מול היסטוריית 90–180 יום ב-PostgreSQL וסימון **Fake Discount** בעלייה מלאכותית של מעל 15% לפני מבצע.
* ניתוח ביקורות ומפרט לזיהוי ביקורות בוטים, חשד לחיקויים והתראות תאימות טכנית (כגון מוצר 110V עם תקע אמריקאי המיועד לישראל).

### 3.6 מחשבון עלות סופית ואופטימיזציית פיצול סל (`landed-cost-calculator` + `smart-cart-tax-optimizer`)
* חישוב דטרמיניסטי ב-Python טהור (אפס חישובי LLM): המרת מט"ח, קיזוז קופונים מאומתים, משלוח וחישוב מע"מ (18% מעל 75 דולר ביבוא אישי לישראל).
* **אופטימיזציית סל רב-פריטים:** חישוב פיצול אופטימלי של סל קניות למספר חבילות מתחת לרף 75 דולר לחיסכון חוקי במע"מ, או איחוד פריטים לעמידה ברף משלוח חינם.

### 3.7 מעקב מחירים, ארנק חיסכון והתראות (Kafka + Redis + MCP)
* ניטור אסינכרוני של `Watchlist` דרך Kafka (`price-drop-events`) ושיגור התראות ל-Telegram/Slack/Email דרך `notify_mcp` בהתאם למסלול המשתמש.
* **Savings Dashboard:** רישום כמותי של החיסכון המצטבר למשתמש מקופונים, פיצול מע"מ והימנעות מ-Fake Discounts.
* **מנוע Affiliate:** הזרקת פרמטרי שותפים אוטומטית לקישורים מאומתים כבסיס למודל עסקי.

### 3.8 שער אבטחה, Guardrails ו-Human-in-the-Loop (`trust-guardrails-hitl-agent`)
* סניטציה דטרמיניסטית ב-Python + סיווג מהיר ב-`gemini-3.5-flash-lite` לסינון Prompt Injection מאתרי קניות וביקורות, ופסילת מוכרים חשודים.
* עצירה מוחלטת והמתנה לאישור משתמש מפורש לפני הוספה לעגלה או הפעלת Checkout.

## 4. מדדי הצלחה ודרישות לא-פונקציונליות (KPIs & SLAs)

| מדד | יעד |
| :--- | :--- |
| **זמן התחלת תגובה (TTFT via SSE)** | פחות מ-1.0 שניה (בזכות חביון נמוך של `gemini-3.5-flash-lite`) |
| **זמן אימות JWT וטעינת פרופיל משתמש** | פחות מ-50ms (עם קאש ב-Redis) |
| **זמן השלמת השוואת מחירים וקופונים מלאה** | פחות מ-4.5 שניות (בביצוע מקבילי) |
| **דיוק חישוב עלות סופית, מע"מ ופיצול סל** | 100% דטרמיניסטי (אפס חישובי LLM) |
| **בידוד משתמשים ומניעת IDOR** | 100% אכיפת `user_id` בשכבת API, DB ו-MCP |
| **הגנת עומס ועלויות AI** | אכיפת מכסות לפי Tier ב-Redis + Context Caching + מעקב טוקנים ועלות ב-OpenTelemetry / Langfuse |
| **חסימת Prompt Injection ופעולות רכישה לא מאושרות** | 100% אכיפה בשכבת Guardrails ו-HITL |
| **שרידות (Resilience)** | המשך פעולה חלקי (Graceful Degradation) גם אם חנות אחת לא מגיבה |
