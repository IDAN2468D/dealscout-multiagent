# 📄 Product Requirements Document (PRD) — DealScout AI Frontend (Next.js) v2.1

## 1. תקציר מנהלים ומטרת הממשק
ממשק ה-Frontend של **DealScout AI** נבנה באמצעות **Next.js 15 (App Router)** כדי להנגיש לצרכנים את צוות הסוכנים האוטונומי (המופעל על **`gemini-3.5-flash-lite`**) בחוויית Web מהירה, שקופה ותומכת עברית מלאה (RTL).

הממשק פותר ארבע בעיות חוויית משתמש מרכזיות בקניות אונליין:
* **חוסר שקיפות במחיר הסופי:** הצגה מיידית ומודגשת של **המחיר הסופי עד הבית בש"ח (Effective Landed Cost)** — כולל המרת מט"ח, קופונים מאומתים, משלוח ומע"מ (18% מעל 75 דולר ביבוא אישי לישראל).
* **חוסר אמון בתהליכי AI ("קופסה שחורה"):** שידור חי בזמן אמת (SSE) של צעדי כל סוכן בצוות, קריאות ה-MCP והבדיקות שבוצעו.
* **מלכודות צרכניות:** חיווי חזותי בולט על מבצעים פיקטיביים (`FAKE_DISCOUNT`), מוכרים חשודים (`BLOCKED_SCAM`) ואי-תאימות לחשמל ישראלי (`110V` / תקע אמריקאי).
* **חיכוך בהתאמה אישית:** הגדרת מועדוני צרכנות וכרטיסי אשראי פעם אחת באזור האישי, וניצולם האוטומטי בכל חיפוש עתידי.

## 3. דרישות פונקציונליות ומסכים עיקריים (Next.js App Router)

### 3.1 הרשמה, התחברות וניהול סשן (`/login`, `/register`, `/auth/callback`)
* טפסי הרשמה והתחברות עם ולידציה מיידית בצד לקוח + כפתור התחברות מהירה עם **Google OAuth2**.
* מסך אימות אימייל והצגת סטטוס המסלול הפעיל (`FREE` / `PRO` / `ADMIN`) לצד מכסת החיפושים היומית שנותרה.
* חידוש סשן שקוף (Silent Refresh) והתנתקות מאובטחת המנקה טוקנים מהזיכרון.

### 3.2 סביבת חיפוש חכמה ומולטי-מודאלית (`/`, `/search`)
* **סרגל חיפוש מאוחד (`OmniSearchBar`):** תמיכה ב-3 מצבי קלט:
  1. שאילתת טקסט חופשית (למשל: *"אוזניות Sony WH-1000XM5 עד 1,100 ש"ח"*).
  2. הדבקת קישור למוצר (URL) לשליפת מפרט וחיפוש חלופות זולות יותר.
  3. העלאה או גרירה (Drag & Drop) של תמונה/צילום מסך לזיהוי דגם ומק"ט באמצעות `gemini-3.5-flash-lite` Vision (`PRO`).
* **פילטרים מהירים:** תקציב מקסימלי בש"ח, ארץ יעד (ברירת מחדל: `IL`), חנויות מועדפות והפעלה/כיבוי של פרופיל מועדוני האשראי.
* **פיד חשיבת סוכנים בזמן אמת (`AgentStreamLogs`):** פאנל צדדי או עליון המזרים חי דרך SSE את פעולת צוות הסוכנים, הכלים שהופעלו (`Elasticsearch`, `ecommerce_mcp`, `coupons_mcp`, `ChromaDB`) וזמן התגובה של כל שלב.
* **כרטיסי עסקאות מדורגים (`DealResultCard`):**
  * מיון ברירת מחדל לפי `total_landed_ils` מהזול ליקר.
  * פירוט מחיר מתרחב: מחיר בסיס, הנחת קופון, משלוח, שורת מע"מ 18% (או תגית ירוקה **"פטור ממע"מ — עד 75 דולר"**).
  * תגיות סמנטיות: `GREAT_DEAL`, `FAIR_PRICE`, `FAKE_DISCOUNT` (באנר אזהרה אדום), ו-`INCOMPATIBLE_SPEC` (אזהרת `110V`).
  * העתקת קוד קופון בלחיצה אחת + כפתורי אימות קהילתי (**"הקופון עבד"** / **"לא עבד"**) עם אחוז הצלחה חי (`success_rate`).

### 3.3 מגירת היסטוריית מחירים וזיהוי הנחה פיקטיבית (`PriceHistoryDrawer`)
* גרף אינטראקטיבי ל-90 עד 180 יום המציג את תנועת המחיר לאורך זמן.
* קווי ייחוס ויזואליים: **שפל היסטורי (All-Time Low)**, **ממוצע 90 יום**, והדגשה אדומה על העלאת מחיר מלאכותית (מעל 15%) שבוצעה לפני מבצע.

### 3.4 אופטימיזציית סל ופיצול חבילות למניעת מע"מ (`/cart-optimizer`)
* ממשק להזנת מספר מוצרים מאותה חנות והרצת אלגוריתם פיצול החבילות הדטרמיניסטי (`PRO`).
* השוואה חזותית ("לפני ואחרי"): **משלוח מאוחד הכולל 18% מע"מ** לעומת **פיצול חכם לחבילות שכל אחת עד 75 דולר (0% מע"מ)** או איחוד לצורך משלוח חינם, כולל תצוגת סכום החיסכון המדויק בש"ח.

### 3.5 מעקב מחירים והתראות (`/watchlist`)
* הוספה, עריכה ומחיקה של מוצרים במעקב, קביעת מחיר יעד בש"ח ובחירת ערוצי התראה (Email / Telegram / Slack לפי מסלול).
* יומן התראות ירידת מחיר שהתקבלו מ-Kafka.

### 3.6 שער אישור אנושי לפני רכישה (`CheckoutApprovalModal` — HITL)
* כל בקשה להוספה אוטומטית לעגלה או מעבר לרכישה פותחת מודאל אישור מפורש המציג:
  * שם המוכר וציון האמינות (`seller_trust_score`), קופונים שיוחלו, פירוט עלות סופית עד הבית ואזהרות תאימות.
  * טיימר תפוגה לאישור + כפתורי **אישור ביצוע (`APPROVED`)** ו-**ביטול (`REJECTED`)** עם שדה הערה אופציונלי.

### 3.7 אזור אישי, ארנק מועדונים ודשבורד חיסכון (`/profile`, `/savings`)
* **ארנק מועדונים (`ClubWalletSelector`):** בחירת מועדוני צרכנות וכרטיסי אשראי (*הייטקזון, חבר, פליי קארד, מקס, כאל, אמריקן אקספרס*) — שמות מועדונים בלבד ללא איסוף פרטי כרטיס אשראי.
* **העדפות קונה (Long-Term Memory):** העדפה לאחריות יבואן רשמי, זמן משלוח מקסימלי וסף אמינות מינימלי למוכר.
* **דשבורד חיסכון (`/savings`):** מדדי חיסכון חודשיים ומצטברים בחלוקה למקורות (קופונים, פיצול מע"מ, הימנעות ממבצעים פיקטיביים) והיסטוריית חיפושים אישית.

### 3.8 פאנל ניהול (`ADMIN` — `/admin`)
* ניטור טוקנים (Input / Output / Cached) ועלות ממוצעת לחיפוש במודל `gemini-3.5-flash-lite`.
* טבלאות מודרציה לקופונים שדווחו כשבורים ולמוכרים שסומנו כהונאה (`BLOCKED_SCAM`).

## 4. דרישות לא-פונקציונליות ויעדי UX

| מדד | יעד |
| :--- | :--- |
| **תמיכת RTL ושפות** | תמיכה מלאה בעברית (`dir="rtl"`), עם בידוד `dir="ltr"` למחירים, קודי קופונים, מק"טים וכתובות URL |
| **ביצועי טעינה (Core Web Vitals)** | `LCP < 1.8s`, `CLS < 0.05`, מעברי ניווט חלקים ב-Next.js App Router |
| **זמן תחילת הצגת זרם SSE** | מתחת ל-1.2 שניות מרגע שליחת החיפוש |
| **נגישות (Accessibility)** | עמידה בתקן WCAG 2.1 AA (ניווט מקלדת, Focus Trap במודאלים, תוויות ARIA) |
| **רספונסיביות** | עיצוב Mobile-First מלא ל-Desktop, Tablet ו-Mobile |
| **אבטחת צד לקוח** | אפס אחסון של `access_token` ב-`localStorage` (זיכרון בלבד) + `Refresh Token` ב-`HttpOnly Cookie` |
| **שרידות (Resilience)** | Skeleton Loaders, Error Boundaries ב-Next.js (`error.tsx`), וכפתור ניסיון חוזר בעת ניתוק SSE |
